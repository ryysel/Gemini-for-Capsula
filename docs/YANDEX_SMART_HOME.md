# Капсула Мини в Яндекс Умном доме

Пошаговая инструкция: как выставить VK Капсулу Мини в Яндекс Умный дом
через собственный навык «Умный дом» в Яндекс Диалогах.

> Это отдельный провайдер. Он управляет **только самой Капсулой**
> (громкость, mute, вкл/выкл). Остальным домом управляет ассистент через
> официальный Yandex IoT API (`yandex_home_find/control/scene`), это другая
> интеграция.

## Что нужно заранее

1. Публичный HTTPS-домен с валидным сертификатом, например
   `https://example.com`.
2. Провайдер `provider.py` на сервере, слушает `127.0.0.1:8788`.
3. nginx location `/capsula/` проксирует на `127.0.0.1:8788`.
4. Файл `/opt/yandex-provider/oauth.env` (600) с:
   - `CLIENT_ID`
   - `CLIENT_SECRET`
   - `PANEL_URL` (панель Капсулы)
   - `PANEL_PASSWORD_FILE`
   - `DEVICE_ROOM` (например, `Гостиная`)
5. systemd-сервис `capsula-provider.service` запущен.

Проверка с сервера:

```bash
curl -sS https://example.com/capsula/health
# {"ok": true, "service": "capsula-provider"}
```

## Шаг 1. Создать навык в Яндекс Диалогах

1. Откройте <https://dialogs.yandex.ru/developer/>.
2. **Создать диалог** → тип **«Умный дом»**.
3. Название: `Капсула Мини`.
4. В поле **Endpoint URL** укажите:
   `https://example.com/capsula`
5. В разделе **Связка аккаунтов**:
   - **URL авторизации:** `https://example.com/capsula/oauth/authorize`
   - **URL токена:** `https://example.com/capsula/oauth/token`
   - **Client ID:** значение `CLIENT_ID` из `oauth.env`
   - **Client secret:** значение `CLIENT_SECRET` из `oauth.env`
   - **Scope:** `iot:view iot:control` (если поле обязательно)
6. Сохраните навык. Для домашнего использования достаточно черновика —
   публиковать в каталог не нужно.

## Шаг 2. Подключить навык в Яндекс Умном доме

1. Откройте <https://yandex.ru/iot> или приложение **«Дом с Алисой»**.
2. **Добавить устройство** → **«Умный дом»** → выберите навык
   **«Капсула Мини»**.
3. Нажмите **«Связать аккаунты»**. Откроется страница OAuth провайдера:
   введите логин/пароль, которые заданы в `oauth.env`/панели.
4. После связки появится устройство **«Капсула Мини»**.
5. Откройте карточку устройства и назначьте комнату, например
   **«Гостиная»**.
6. Проверьте:
   - ползунок громкости;
   - кнопку mute/unmute;
   - вкл/выкл.

## Шаг 3. Голосовые команды

Алиса понимает карточку как медиаустройство:

- «Алиса, включи капсулу мини»
- «Алиса, выключи капсулу мини»
- «Алиса, увеличь звук на капсуле мини»
- «Алиса, сделай капсулу мини потише»
- «Алиса, выключи звук на капсуле мини»

## Как это устроено

Провайдер реализует протокол Яндекс Умного дома:

- `GET /v1.0/user/devices` — список устройств;
- `POST /v1.0/user/devices/query` — текущее состояние;
- `POST /v1.0/user/devices/action` — управление.

Тип устройства: `devices.types.media_device`.
Умения:

- `devices.capabilities.on_off` — вкл/выкл (mute/unmute);
- `devices.capabilities.range` / `volume` — громкость 0–100;
- `devices.capabilities.toggle` / `mute` — mute.

Команды провайдер переводит в локальную панель Капсулы
(`capsule-ipc`/`VOL`), поэтому громкость меняется и в панели, и в ALSA,
и в AirPlay.

Относительная громкость: Яндекс присылает `range.volume` с
`relative: true` и `value: ±10`; провайдер читает текущую громкость и
прибавляет/вычитает значение.

## Безопасность

- Только HTTPS, сертификат на публичном домене.
- `oauth.env` и `tokens.json` — права `600`, не в Git и не в чате.
- nginx `limit_req` на `/capsula/oauth/` (10 r/m, burst 5).
- fail2ban `capsula-oauth`: 10 ответов `401/429` за 10 минут → бан 1 час;
  локальные адреса игнорируются.
- Client secret не публикуется; в скриншотах и README — только плейсхолдеры.

## Если не работает

- **401/403 при связке** — проверьте `CLIENT_ID`/`CLIENT_SECRET`, URL
  авторизации и токена, логи `capsula-provider.service`.
- **Устройство не появилось** — навык сохранён? аккаунт связан? endpoint
  доступен снаружи? Проверьте `https://example.com/capsula/health`.
- **Громкость не меняется** — панель Капсулы доступна? `DEVICE_ROOM`
  совпадает с комнатой? В логах провайдера видно `action` и `query`.
- **Токен истёк** — повторите связку аккаунтов в карточке навыка.

## Скриншоты для README

Для публичной инструкции лучше сделать три скриншота:

1. Консоль Яндекс Диалогов: навык «Умный дом», Endpoint URL и связка
   аккаунтов (секреты закрыты).
2. Яндекс Умный дом: карточка «Капсула Мини» с громкостью и mute.
3. Голосовая команда «Алиса, сделай капсулу мини потише» и ползунок.

Перед публикацией уберите из кадров: домен, IP, client secret, токены,
личные названия комнат и устройств.
